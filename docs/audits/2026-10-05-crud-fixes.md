# CRUD 审计修复与验收

对应 [原始审计](2026-10-05-crud-audit.md) 的 10 项问题。本轮修改生产实现，并增加回归测试；原始审计保留作为修复前的证据。

## 结构变化

| 原问题 | 修复后的机制 | 验证 |
| --- | --- | --- |
| 内存表 UPDATE 未同步唯一键 | 在约束锁和变更锁内统一退休旧键、发布新键；主键也走同一维护协议 | 内存表、段文件两种状态均验证新键拒重、旧键复用、DELETE 后重插 |
| 事务 UPDATE 失败仍修改自己的插入行 | 所有赋值先验证，替换只形成计划；新镜像先写入私有语句事务，全部成功后转移所有权 | 未知列、NULL、真实首批镜像写入后的注入失败；失败后继续 UPDATE、COMMIT |
| DECIMAL scale 丢失 | 内存表和段文件统一使用目标列 scale、会话时区转换常量赋值 | DECIMAL 原始值 456/789；时区 +8 下 INSERT 与 UPDATE 时间戳一致 |
| NOT NULL 漏检 | 扫描和写入前检查赋值的 nullable/primary_key 约束 | 失败语句保留原值 |
| DELETE 读错误发生在部分删除之后 | 自动提交和显式事务均先完成所有读取、谓词计算和计划；事务事件也延后批量登记 | 损坏段文件时保留普通内存行、事务自己的插入行及约束状态 |
| 默认窗口 AVG 为 NULL | 所有聚合共享维护有效值计数的帧累加器 | 默认 RANGE、含 NULL 和重复排序键的 AVG |
| Window / TopN 缺预算 | 算子持有 RAII 共享内存预约，按保留数据和分配阶段的峰值检查本地与全局预算 | 1 KiB/1 MiB 预算下拒绝超限，正常窗口和 TopN OFFSET 测试通过 |
| 内存表 UPDATE / DELETE 复制整批宽数据 | 冻结为共享叶缓冲；删除组合行位置，常量更新组合旧叶与常量叶；限制碎片并按几何阈值回收死数据 | 连续 100 次更新不形成父快照链；稀疏选择释放大部分死数据；NULL 检查不物化宽值缓冲 |
| INSERT 索引缺失时全表键物化 | 键扫描改为回调；分批排序、二路外部归并、流式生成普通索引 base；REBUILD、REPLACE bootstrap、段重写重建共用 | 40,000 个逆序键触发多 run 归并；扫描失败保留旧 base、清理临时文件；重启仍可查 |
| 窗口逐行重建帧导致二次复杂度 | 帧边界移动只增删差集；MIN/MAX/DISTINCT 维护有序多重集合；peer / RANGE 边界二分搜索 | ROWS、RANGE、默认帧与移动聚合的现有及新增语义测试 |

## 同类路径收敛

- 事务 DELETE 的自己的插入行和订阅事件也进入语句计划，防止读失败留下可提交的半条语句。
- 事务预算先检查再记账；事件先批量收费再登记，失败不会消耗预算或残留部分事件。
- UPDATE 的赋值、计划、引入键校验、索引追加共用预算；键校验临时状态销毁时退还费用。索引精确退休另外限制键字节数，超限切换为快照失效。
- 共享列的取值、比较、求和、gather、NULL 位图和热点缓存重建均已接入，避免更换存储表示后读出错误结果。
- UPDATE 仅在实际进入修改阶段后的失败路径失效索引和热点缓存，规划失败不会触发无意义的重建。

## 验收与边界

- `cargo test --lib`：790 通过，4 个既有诊断测试忽略，无失败。
- 17 个相关集成测试套件：177 通过，无失败，覆盖 CRUD、约束、窗口、TopN、schema drift、并发、事务与订阅。
- `cargo check --all-targets`、`git diff --check` 通过；内存预算端到端复测程序通过。

新增测试位于 `src/sql/execution/engine_test/crud_root_regressions.rs` 和 `src/storage/index/index_manager_test.rs`。`examples/audit_memory_probe.rs` 已改为断言预算生效。

Window / TopN 超预算时返回可重试的 `ResourceBusy`。Window 仍需物化输入，未在本轮实现窗口分区磁盘溢写。内存计量是保守估计；保留旧快照的并发读者仍会持有其共享叶，直到读者释放。

DELETE 的段 footer 持久化失败沿用已有部分成功语义，但会完成索引、热点缓存和行数清理；本轮修复了读取/计算失败提前落入该状态的问题。UPDATE 镜像的持久化提交发生 I/O 失败时仍沿用已有的提交结果不确定语义。未穷举所有磁盘故障或并发交错，测试通过不等于证明不存在其他缺陷。
